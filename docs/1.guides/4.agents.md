---
title: Connect an AI agent
description: Let Claude, ChatGPT, Cursor, or another MCP client read your money and answer questions about it.
---

ViteHub Finance has an MCP server. An AI agent that speaks MCP can connect to it and read your accounts, transactions, recurring payments, spending, and forecast. It can also categorize transactions.

An agent acts as you. It sees exactly what you see, including your own private accounts. It never sees other members' private accounts, and it never manages people or household settings.

## The server URL

Open **Settings** › **Agents**. Under **Connect an agent**, copy the **MCP server URL**. It's your ViteHub Finance address followed by `/mcp`, for example `https://finance.example.com/mcp`.

## Connect with OAuth

Most agents sign in through your browser, with OAuth. You don't need a key.

### Claude Code

Run this in a terminal, with your own server URL:

```bash
claude mcp add --transport http vitehub-finance https://finance.example.com/mcp
```

The first time, Claude Code opens your browser to ask for permission.

### Claude Desktop, Cursor, VS Code, and other JSON configs

Add the server to the client's MCP configuration:

```json
{
  "mcpServers": {
    "vitehub-finance": {
      "type": "http",
      "url": "https://finance.example.com/mcp"
    }
  }
}
```

The client opens your browser to sign in.

### ChatGPT and other clients

Give the client the MCP server URL. If it supports MCP sign-in with OAuth, it opens your browser the same way.

### Allow access

In the browser, sign in to ViteHub Finance if you aren't already. The page asks whether to allow the agent, by name, to read your household's finances. It lists what the agent can do:

- Read the accounts, balances, and transactions you can see
- Read recurring payments, budgets, goals, and the forecast
- Categorize transactions and add notes where you may edit
- Never manage people or household settings

The page also says where **Allow** sends the access, for example an app on this computer or a website. Only allow it if you started this connection from an agent that runs there. Click **Allow** or **Deny**.

The agent then shows up under **Connected agents**.

::note
You can't create an account from this page. Sign up in ViteHub Finance first.
::

## Connect with an API key

Use an API key for scripts and clients that can't sign in with OAuth.

::steps
### Create a key

In **Settings** › **Agents**, under **API keys**, click **Create key**. Give it a **Name** after what will use it, like "Home server". Pick when it **Expires**: 30 days, 90 days, 1 year, or **Never**.

### Copy it

Click **Copy key** and store it somewhere safe, like a password manager. This is the only time it's shown. If you lose it, delete it and create a new one.

### Send it as a bearer token

Add it as an `Authorization` header in the client's configuration:

```json
{
  "mcpServers": {
    "vitehub-finance": {
      "type": "http",
      "url": "https://finance.example.com/mcp",
      "headers": { "Authorization": "Bearer fin_…" }
    }
  }
}
```
::

Keys start with `fin_`. A key acts as you, like an agent signed in with OAuth. Each key allows up to 120 requests a minute.

The list of keys shows when each one was last used and when it expires.

## Tools

The server has four tools: two that read and two that change data. Every tool that reads takes an optional `scope`. Use `household`, the default, for your accounts plus the ones others share, or `me` for only your own.

| Tool | What it does |
| --- | --- |
| `get_finances` | Reads your finances, one `view` at a time. `overview` (the default): net worth, this month's money in and out next to last month's, spending by category, recurring payments due in the next 14 days, the latest transactions, staking, and connections that need attention. `accounts`: every account you can see with its kind, balance, owner, whether it's shared, and its id. `account`: one account's holdings, staking, and balance trend. `spending`: one month by category. `recurring`: subscriptions, bills, and income that repeat, with totals and ways to save. `forecast`: your balance 1 to 24 months ahead, with a likely range and the payments expected in the next 30 days. |
| `search_transactions` | Finds transactions by text, date range, account, category, or direction, in or out. Returns up to 100 per page, 25 by default, plus the count and totals in and out over every match. |
| `update_transaction` | Sets a transaction's category, by id or name, and its note. With `applyToSimilar`, it also saves a rule and categorizes similar uncategorized transactions. |
| `add_transactions` | Adds transactions you give the agent, for example rows it read from a statement ViteHub Finance can't import, to an account you may edit, or to a new manual account. Rows already there are skipped, and your rules run on the new ones. |

Totals are in your household's currency. Each account's balance and each transaction's amount are in that account's own currency.

## What agents can and can't do

`update_transaction` and `add_transactions` are the only tools that change anything, and only on accounts you may edit. Rules won't change a category an agent set. An agent can turn a statement in any format into transactions: ask it to read the file and add the rows to an account, or to a new manual account it creates for you.

Agents and API keys can't:

- See other members' private accounts, or transactions others hid from the household
- Hide or unhide transactions
- Delete accounts, change who sees an account, or archive one
- Connect, sync, or remove banks, exchanges, wallets, and brokers
- Invite or remove people, leave the household, or change household settings
- Disconnect agents

Those stay with you, in the browser.

Agents see your own transactions that you hid from the household. The server tells agents to leave them out of anything meant for other members.

::tip
Ask the agent to start with `get_finances`. Its overview gives a quick picture of the household before you ask about details.
::

## Revoke access

### Disconnect an agent

In **Settings** › **Agents**, under **Connected agents**, click **Disconnect** next to the agent, then confirm. It loses access within the hour. To connect again, it has to ask for your permission again.

### Delete an API key

Under **API keys**, click the delete button next to the key, then **Delete key**. Anything using it stops working at once. You can't undo this.

Each person sees and manages only their own agents and keys.
