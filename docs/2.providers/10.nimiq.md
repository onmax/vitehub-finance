title: Nimiq
description: Watch a Nimiq address to see its balance, staked NIM, and transactions in your household's currency.

ViteHub Finance watches a Nimiq address. Watch-only by address means it reads what anyone can see on the blockchain for that address. It never has a private key, so it can never spend or move your coins.

## Addresses it accepts

- `NQ` followed by two check digits and 32 characters, with or without spaces, in any case

Each wallet watches one address. Nimiq addresses carry check digits, so ViteHub Finance catches a typo before it adds the wallet. Anything else gets "That isn't a valid Nimiq address."

## What it reads

- **Balance.** The NIM at the address, staked NIM included.
- **Transactions.** Yes. Each send and receive becomes a transaction in ViteHub Finance, counted as a transfer. Block and staking rewards count as income. Moving NIM into or out of staking doesn't add a transaction, because the balance already counts staked NIM.
- **History.** The first sync reads up to the 2,000 most recent transactions. Later syncs read the last ten days.
- **Balance chart.** ViteHub Finance rebuilds it day by day from those transactions, up to a year back.

## Where the data comes from

- **Source.** The public NimiqWatch node at `rpc.nimiqwatch.com`. No account or key is needed.
- **Value.** NIM at CoinGecko's price, in your household's currency. Each transaction uses the price on its day. Transactions older than a year use the oldest price available.
- **Sync.** Every morning, and when you select **Sync now** on its row.

## Add the wallet

1. Open **Crypto** in the sidebar and select **Connect** on the Nimiq tile.
2. Paste the public address into **Address**.
3. Optionally, give it a **Name**. Without one, it's called Nimiq wallet.
4. Select **Add wallet**.

The server checks the address before it saves it, then reads it right away.

::warning
Only paste the public address. Never paste a seed phrase or private key.
::

For more on Nimiq, see [nimiq.com](https://www.nimiq.com/).
