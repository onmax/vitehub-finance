title: XRP Ledger
description: Watch an XRP Ledger address to see its balance and transactions in your household's currency.
---

ViteHub Finance watches an XRP Ledger address. Watch-only by address means it reads what anyone can see on the ledger for that address. It never has a private key, so it can never spend or move your coins.

## Addresses it accepts

- Classic addresses, which start with `r` and have 25 to 35 characters

Each wallet watches one address. It doesn't accept X-addresses, which start with `X`. Anything else gets "That isn't a valid XRP Ledger address."

## What it reads

- **Balance.** The XRP at the address. It leaves out XRP locked in an escrow. An address nobody has funded yet reads as zero.
- **Transactions.** Yes. Each transaction that moved the address's XRP becomes a transaction in ViteHub Finance, counted as a transfer. That includes payments, escrows, and swaps on the ledger's exchange. It leaves out tokens, other currencies, and transactions that only cost a fee.
- **History.** The first sync reads up to the 2,000 most recent transactions. Later syncs read the last ten days.
- **Balance chart.** ViteHub Finance rebuilds it day by day from those transactions, up to a year back.

## Where the data comes from

- **Source.** Public XRP Ledger servers, tried in order: `s1.ripple.com`, `s2.ripple.com`, then `xrplcluster.com`. When one is busy, the next one answers. No account or key is needed.
- **Value.** XRP at CoinGecko's price, in your household's currency. Each transaction uses the price on its day. Transactions older than a year use the oldest price available.
- **Sync.** Every morning, and when you select **Sync now** on its row.

## Add the wallet

1. Open **Crypto** in the sidebar and select **Connect** on the XRP Ledger tile.
2. Paste the public address into **Address**.
3. Optionally, give it a **Name**. Without one, it's called XRP Ledger wallet.
4. Select **Add wallet**.

The server checks the address before it saves it, then reads it right away.

> [!WARNING]
> Only paste the public address. Never paste a seed phrase or private key.

For more on XRP Ledger accounts, see [xrpl.org](https://xrpl.org/docs/concepts/accounts).
