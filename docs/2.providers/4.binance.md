title: Binance

ViteHub Finance reads your Binance balances through an API key that can only read. It never trades or moves funds.

## What it reads

- The balance of every coin you hold in your spot wallet and in Simple Earn. Simple Earn coins count toward the same coin.
- Free and locked amounts together, as one balance per coin.
- Once a day, and when you sync by hand.

## What it can't do

- Trade, withdraw, or move funds, with a read-only key.
- See your Binance password or sign in as you.
- Read your trades, deposits, or withdrawals. Only balances come in.

## Create a read-only key

::steps
### Open API Management
In Binance, open **API Management** and create a system-generated key.

### Keep only Enable Reading
Keep **Enable Reading** on. ViteHub Finance reads your balances with it.

### Leave everything else off
No trading, no withdrawals.

### Copy the key
Copy the API key and its secret key. You paste both into ViteHub Finance.
::

For Binance's own steps, see [How to create an API key](https://www.binance.com/en/support/faq/detail/360002502072).

## Connect it in ViteHub Finance

1. Open **Crypto** in the sidebar and select **Connect** on the Binance tile.
2. Paste the key into **API key** and the secret into **Secret key**.
3. Optionally, give it a **Name**. Without one, it's called Binance.
4. Select **Check and connect**.

The server tries the key with Binance before it saves anything. If Binance refuses the key, the server stores nothing. If the key works, the server stores it encrypted and starts the first sync right away.

## Sync

The connection syncs every morning. To sync sooner, select **Sync now** on its row on the **Crypto** page.

## How it's valued

The account is worth the sum of its coins in your household's currency:

- Coins use CoinGecko's current price. Coins CoinGecko can't price use Kraken's public ticker.
- Any cash balance, such as EUR or USD, uses the ECB exchange rate.
- A coin that neither source can price counts as zero.

## History

Binance connections don't read past transactions, so there is nothing to backfill. The balance chart starts on the day you connect, and each sync saves that day's balance. Before that day, the overview counts the account at its first balance, so connecting it doesn't show as growth.

## Common errors

| Message | What it means |
| --- | --- |
| Binance rejected the API key. | The key or secret is wrong, or the key can't read. Check both, or create a new key and connect again. |
| Binance blocks requests from the region this server runs in. | Binance refuses the server's location. Another key won't help. |
| Binance is limiting requests. | Binance is turning requests away for now. Try again in a few minutes. |
| Binance returned an error. | Binance had a problem on its side. Try again later. |
| You've already connected this. | This key is already connected. Sync or remove the existing connection instead. |

If a daily sync fails, the error shows on the connection's row and it tries again the next morning. To use a new key, remove the connection and connect again.

For connecting in general, see [Connect accounts](/docs/guides/connect-accounts).
