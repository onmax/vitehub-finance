ViteHub Finance watches an Ethereum address. Watch-only by address means it reads what anyone can see on the blockchain for that address. It never has a private key, so it can never spend or move your coins.

## Addresses it accepts

- `0x` followed by 40 hexadecimal characters, in any case

Each wallet watches one address. Anything else gets "That isn't a valid Ethereum address."

## What it reads

- **Balance.** The ETH at the address, and these tokens when it holds them: USDC, USDT, DAI, and WETH. ViteHub Finance doesn't see other tokens: there's no keyless way to list every token an address holds.
- **Other networks.** The same address can hold coins on other networks. Add it again as a [Polygon](/docs/providers/polygon) wallet to see those.
- **Transactions.** No. Only the balance comes in.
- **Balance chart.** Starts on the day you add the wallet. Each sync saves that day's value.

## Where the data comes from

- **Source.** The public Ethereum nodes at `ethereum-rpc.publicnode.com`, then `rpc.flashbots.net` when the first one fails. No account or key is needed.
- **Value.** ETH and each token at CoinGecko's price, in your household's currency.
- **Sync.** Every morning, and when you select **Sync now** on its row.

## Add the wallet

1. Open **Crypto** in the sidebar and select **Connect** on the Ethereum tile.
2. Paste the public address into **Address**.
3. Optionally, give it a **Name**. Without one, it's called Ethereum wallet.
4. Select **Add wallet**.

The server checks the address before it saves it, then reads it right away.

> [!WARNING]
> Only paste the public address. Never paste a seed phrase or private key.

For more on Ethereum wallets, see [ethereum.org](https://ethereum.org/wallets/).
