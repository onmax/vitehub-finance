ViteHub Finance watches a Solana address. Watch-only by address means it reads what anyone can see on the blockchain for that address. It never has a private key, so it can never spend or move your coins.

## Addresses it accepts

- A Base58 address of 32 to 44 characters

Each wallet watches one address. Anything else gets "That isn't a valid Solana address."

## What it reads

- **Balance.** The SOL at the address. ViteHub Finance doesn't count tokens the address holds.
- **Transactions.** No. Only the balance comes in.
- **Balance chart.** Starts on the day you add the wallet. Each sync saves that day's value.

## Where the data comes from

- **Source.** Solana's public endpoint at `api.mainnet-beta.solana.com`. No account or key is needed.
- **Value.** SOL at CoinGecko's price, in your household's currency.
- **Sync.** Every morning, and when you select **Sync now** on its row.

## Add the wallet

1. Open **Crypto** in the sidebar and select **Connect** on the Solana tile.
2. Paste the public address into **Address**.
3. Optionally, give it a **Name**. Without one, it's called Solana wallet.
4. Select **Add wallet**.

The server checks the address before it saves it, then reads it right away.

> [!WARNING]
> Only paste the public address. Never paste a seed phrase or private key.

For more on Solana wallets, see [solana.com](https://solana.com/wallets).
