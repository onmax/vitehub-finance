Interactive Brokers (IBKR) connects through its Flex Web Service. You make two things in IBKR's [Client Portal](https://www.interactivebrokers.com/portal/): an Activity Flex Query, which decides what the app reads, and a token that runs it. Then you paste both into the app.

The token only fetches Flex reports. It can't trade, move money, or change your account. The app stores it encrypted.

IBKR's own guide to Flex Queries is at [ibkrguides.com](https://www.ibkrguides.com/clientportal/performanceandstatements/flex3.htm).

## Create the Flex Query

Both the query and the token are in the Client Portal, under **Performance & Reports › Flex Queries**.

::steps
### Open Flex Queries
Sign in to IBKR's Client Portal and open **Performance & Reports › Flex Queries**.

### Start a new query
Next to **Activity Flex Query**, click **+**. Name the query, for example `ViteHub Finance`.

### Pick the five sections
Under **Sections**, tick these five. **Account Information** can stay.
- **Open Positions**
- **Cash Report**
- **Trades**
- **Cash Transactions**
- **Net Asset Value (NAV) in Base**

In each one, choose **Select All** for the fields. Under **Options**, choose **Summary** for Open Positions and **Execution** for Trades.

### Set the period
Under **Delivery Configuration**, set **Period** to **Last 365 Calendar Days**. Any **Format** works. Leave the rest, and **Filters**, as they are.

### Keep the date format
Keep **Date Format** at `yyyyMMdd`, IBKR's default. The app also reads `yyyy-MM-dd` and `yyyy/MM/dd`, but no other format.

### Save and note the Query ID
Click **Continue** and save. Then open the query's info (the **i** next to it) and note its **Query ID**, a number.
::

### Quicker with Configure with AI

IBKR's Configure with AI can build the query for you. In the app's connect dialog, click **Copy prompt** to copy this text, then give it to Configure with AI:

```text
Create an Activity Flex Query named ViteHub Finance with these five sections and nothing else. Open Positions at the Summary level of detail, with all fields, including Account ID, Currency, Asset Class, Symbol, Description, Conid, ISIN, Quantity, Mark Price, and Position Value. Cash Report per currency, with all fields, including Currency and Ending Cash. Trades at the Execution level of detail, with all fields, including Trade ID, Trade Date, Symbol, Description, Quantity, Trade Price, Net Cash, and Currency. Cash Transactions, with all fields, including Type, Date/Time, Amount, Currency, Description, and Transaction ID. Net Asset Value (NAV) in Base, with all fields, including Report Date and Total. Format: XML. Period: Last 365 Calendar Days. Date Format: yyyyMMdd. Keep Display Account Alias in Place of Account ID and Breakout by Day on No, and add no filters.
```

Check the query it makes against the steps above, then note its Query ID.

## Create the token

::steps
### Open the Flex Web Service settings
On the same **Flex Queries** page, open **Flex Web Service Configuration**. It's the gear next to **Flex Web Service**.

### Turn it on
Turn the Flex Web Service on.

### Generate a token
Generate a new token. Leave **Valid For IP Address** empty, since the app's server has no fixed address. Pick the longest expiry.

### Copy it
Copy the token. Generating another one later replaces this one.
::

> [!WARNING]
> A token lasts 6 hours unless you pick a longer expiry. Pick the longest one, or the connection stops syncing the same day.

## Connect it in the app

::steps
### Open Interactive Brokers
Go to **Investments** in the sidebar and click **Connect** on **Interactive Brokers**.

### Paste the token and Query ID
Paste the token in **Flex token** and the number in **Query ID**.

### Check and connect
Click **Check and connect**. The app runs the query once to check it. Nothing is saved until that works.
::

The connect dialog also has **Open IBKR's Client Portal** and a short version of the steps on this page.

## What it imports

Each IBKR account in the query becomes an **Investments** account in the app, named **Interactive Brokers** and the account ID. One query can cover several linked accounts.

For each account, the app reads:

- Open positions, at IBKR's mark prices.
- Cash in each currency.
- Trades. Each one becomes a transaction like "Buy 10 ABC at 25 USD". Trades count as transfers, since they swap cash for an investment inside the account.
- Cash movements. Deposits and withdrawals count as transfers, since they move your own money. Dividends, withholding tax, interest, and fees count as normal transactions.
- Daily value history: the account's whole value on each past day, from the NAV section. With **Last 365 Calendar Days**, that's up to a year. It fills the account's balance chart for days that don't have a value yet.

The account's value is its positions and cash, at IBKR's prices, converted to the household's currency.

## Sync

The connection syncs every morning. To sync sooner, click **Sync now** on its row in **Investments**.

IBKR takes a moment to prepare each report. If it isn't ready after about 30 seconds, the sync stops and asks you to try again in a few minutes.

## Token expiry and renewal

When the token expires, syncing stops. The connection shows **Sync failed** and the message "The Flex token has expired. Generate a new one and connect again." Your accounts and their history stay.

To renew it:

::steps
### Make a new token
In IBKR's **Flex Web Service Configuration**, generate a new token with the longest expiry, and copy it.

### Connect again
In the app, go to **Investments** and open **Interactive Brokers**. Since it's already connected, the button reads **Connect another Interactive Brokers account**, or **Add another** on its tile. Click it, then paste the new token and the same **Query ID**.
::

The app recognizes the query and gives the existing connection the new token. Your accounts and their history stay. Do this as the person who connected it first. Someone else connecting the same query creates a separate connection.

## Common errors

| Message | What to do |
| --- | --- |
| The Flex Query's dates can't be read. Set its Date Format to yyyyMMdd | Edit the query in IBKR's Flex Queries, set **Date Format** to `yyyyMMdd`, and save. Then sync again. |
| The Flex token has expired. Generate a new one and connect again. | Make a new token, as in **Token expiry and renewal** on this page. |
| The Flex token isn't valid. Copy it again from Flex Web Service Configuration. | Paste the token again. A newer token replaces older ones. |
| The Query ID isn't valid. Copy it from the query's info in Flex Queries. | Check the number in the query's info. |
| The Flex Web Service is off for this account. Turn it on under Flex Web Service Configuration. | Turn the service on, then try again. |
| The Flex token only works from one IP address. Generate one with 'Valid for IP Address' left empty. | Generate a new token without an IP address. |
| This is a legacy Flex Query. Create a new Activity Flex Query. | Create a new Activity Flex Query with the steps above. |
| An account in the Flex Query isn't valid. Check the query's Accounts setting. | Fix the accounts the query covers. |
| The Flex Query has no accounts in it. Check its Accounts setting. | Make sure the query covers at least one account. |
| The Flex Query needs the Open Positions and Cash Report sections. | Add the sections in IBKR's Flex Queries and save. |
| Interactive Brokers couldn't validate the request. Check the Flex token and the Query ID. | Paste both again. |
| Interactive Brokers is limiting requests for this Flex token. Try again in a few minutes. | Wait a few minutes. |
| Interactive Brokers is still preparing the statement. Try again in a few minutes. | Wait a few minutes, then click **Sync now**. |
