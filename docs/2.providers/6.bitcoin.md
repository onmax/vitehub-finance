title: Bitcoin
description: Watch a Bitcoin address to see its balance and transactions in your household's currency.
---

ViteHub Finance watches a Bitcoin address. Watch-only by address means it reads what anyone can see on the blockchain for that address. It never has a private key, so it can never spend or move your coins.

## Addresses it accepts

- Addresses that start with `1`
- Addresses that start with `3`
- Addresses that start with `bc1`, all lowercase or all uppercase

Each wallet watches one address. It doesn't accept an extended public key, the kind that starts with `xpub`. Anything else gets "That isn't a valid Bitcoin address."

## What it reads

- **Balance.** The BTC at the address, including payments still waiting for a block.
- **Transactions.** Yes. Each confirmed transaction becomes a transaction in ViteHub Finance, counted as a transfer. Mining rewards count as income.
- **History.** The first sync reads up to the 250 most recent transactions. Later syncs read the last ten days.
- **Balance chart.** ViteHub Finance rebuilds it day by day from those transactions, up to a year back.

## Where the data comes from

- **Source.** The public `mempool.space` API. No account or key is needed.
- **Value.** BTC at CoinGecko's price, in your household's currency. Each transaction uses the price on its day. Transactions older than a year use the oldest price available.
- **Sync.** Every morning, and when you select **Sync now** on its row.

## Add the wallet

1. Open **Crypto** in the sidebar and select **Connect** on the Bitcoin tile.
2. Paste the public address into **Address**.
3. Optionally, give it a **Name**. Without one, it's called Bitcoin wallet.
4. Select **Add wallet**.

The server checks the address before it saves it, then reads it right away.

::warning
Only paste the public address. Never paste a seed phrase or private key.
::

For more on how Bitcoin works, see [bitcoin.org](https://bitcoin.org/en/how-it-works).
