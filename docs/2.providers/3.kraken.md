title: Kraken
description: Connect Kraken with a read-only API key to see every coin you hold there in your household's currency.
---

ViteHub Finance reads your Kraken balances through an API key that can only read. It never trades or moves funds.

## What it reads

- The balance of every coin you hold: spot, staked, and earn balances. Staked coins count toward the same coin.
- Cash you hold on Kraken, such as EUR or USD.
- Once a day, and when you sync by hand.

## What it can't do

- Trade, withdraw, or move funds, with a read-only key.
- See your Kraken password or sign in as you.
- Read your trades, deposits, or withdrawals. Only balances come in.

## Create a read-only key

::steps
### Open the API settings
In Kraken, open **Settings › API** and create a new key.

### Turn on Query Funds
Under the key's permissions, turn on **Query Funds**. ViteHub Finance reads your balances with it.

### Leave everything else off
Leave trading and withdrawals off.

### Copy the key
Copy the API key and its private key. You paste both into ViteHub Finance.
::

For Kraken's own steps, see [How to create an API key](https://support.kraken.com/articles/360000919966-how-to-create-an-api-key).

## Connect it in ViteHub Finance

1. Open **Crypto** in the sidebar and select **Connect** on the Kraken tile.
2. Paste the key into **API key** and the private key into **Private key**.
3. Optionally, give it a **Name**. Without one, it's called Kraken.
4. Select **Check and connect**.

The server tries the key with Kraken before it saves anything. If Kraken refuses the key, the server stores nothing. If the key works, the server stores it encrypted and starts the first sync right away.

## Sync

The connection syncs every morning. To sync sooner, select **Sync now** on its row on the **Crypto** page.

## How it's valued

The account is worth the sum of its coins in your household's currency:

- Coins use CoinGecko's current price. Coins CoinGecko can't price use Kraken's public ticker.
- Cash such as EUR or USD uses the ECB exchange rate.
- A coin that neither source can price counts as zero.

## History

Kraken connections don't read past transactions, so there is nothing to backfill. The balance chart starts on the day you connect, and each sync saves that day's balance. Before that day, the overview counts the account at its first balance, so connecting it doesn't show as growth.

## Common errors

| Message | What it means |
| --- | --- |
| Kraken rejected the API key. | The key or private key is wrong, or the key doesn't have Query Funds. Create a new key and connect again. |
| The Kraken private key isn't valid. | What you pasted as the private key can't be read as one. Copy it again from Kraken's API settings. |
| Kraken is limiting requests. | Kraken is turning requests away for now. Try again in a few minutes. |
| Kraken returned an error. | Kraken had a problem on its side. Try again later. |
| You've already connected this. | This key is already connected. Sync or remove the existing connection instead. |

If a daily sync fails, the error shows on the connection's row and it tries again the next morning. To use a new key, remove the connection and connect again.

For connecting in general, see [Connect accounts](/docs/guides/connect-accounts).
