title: Polygon
description: Watch an address on Polygon to see its POL and common tokens in your household's currency.

ViteHub Finance watches an address on Polygon. Watch-only by address means it reads what anyone can see on the blockchain for that address. It never has a private key, so it can never spend or move your coins.

A MetaMask or other Ethereum address works on Polygon too: it's the same address on another network, with its own balances. To see both, add it once as an [Ethereum](/docs/providers/ethereum) wallet and once as a Polygon wallet.

## Addresses it accepts

- `0x` followed by 40 hexadecimal characters, in any case

Each wallet watches one address. Anything else gets "That isn't a valid Polygon address."

## What it reads

- **Balance.** The POL at the address, and these tokens when it holds them: USDC, USDC.e (USDC bridged from Ethereum), USDT, DAI, and WETH. ViteHub Finance doesn't see other tokens: there's no keyless way to list every token an address holds.
- **Transactions.** No. Only the balance comes in.
- **Balance chart.** Starts on the day you add the wallet. Each sync saves that day's value.

## Where the data comes from

- **Source.** The public Polygon nodes at `polygon-bor-rpc.publicnode.com`, then `polygon.drpc.org` when the first one fails. No account or key is needed.
- **Value.** POL and each token at CoinGecko's price, in your household's currency.
- **Sync.** Every morning, and when you select **Sync now** on its row.

## Add the wallet

1. Open **Crypto** in the sidebar and select **Connect** on the Polygon tile.
2. Paste the public address into **Address**.
3. Optionally, give it a **Name**. Without one, it's called Polygon wallet.
4. Select **Add wallet**.

The server checks the address before it saves it, then reads it right away.

> [!WARNING]
> Only paste the public address. Never paste a seed phrase or private key.

For more on Polygon, see [polygon.technology](https://polygon.technology/).
