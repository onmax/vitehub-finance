ViteHub Finance reads your Coinbase balances through an API key that can only view. It never trades or moves funds.

## What it reads

- The balance of every coin you hold, across all your Coinbase accounts.
- Once a day, and when you sync by hand.

## What it can't do

- Trade, withdraw, or move funds, with a read-only key.
- See your Coinbase password or sign in as you.
- Read your trades, deposits, or withdrawals. Only balances come in.

## Create a read-only key

::steps
### Open the Coinbase Developer Platform
In the Coinbase Developer Platform, create a Secret API key.

### Give it View permission only
Turn on **View**. ViteHub Finance reads your balances with it.

### Leave everything else off
Leave every other permission off.

### Copy the key name and private key
Copy the key's name, which looks like `organizations/…/apiKeys/…`, and its private key. You paste both into ViteHub Finance.
::

For Coinbase's own reference, see [API key authentication](https://docs.cdp.coinbase.com/coinbase-app/authentication-authorization/api-key-authentication).

## Connect it in ViteHub Finance

1. Open **Crypto** in the sidebar and select **Connect** on the Coinbase tile.
2. Paste the key's name into **Key name**.
3. Paste the whole private key into **Private key**. To check what you pasted, select the eye icon. The field opens into a box that shows the whole key.
4. Optionally, give it a **Name**. Without one, it's called Coinbase.
5. Select **Check and connect**.

The server tries the key with Coinbase before it saves anything. If Coinbase refuses the key, the server stores nothing. If the key works, the server stores it encrypted and starts the first sync right away.

> [!TIP]
> Both kinds of Coinbase private key work. An EC key is a block of lines. Paste it with its `BEGIN` and `END` lines. An Ed25519 key is one line.

## Sync

The connection syncs every morning. To sync sooner, select **Sync now** on its row on the **Crypto** page.

## How it's valued

The account is worth the sum of its coins in your household's currency:

- Coins use CoinGecko's current price. Coins CoinGecko can't price use Kraken's public ticker.
- Any cash balance, such as EUR or USD, uses the ECB exchange rate.
- A coin that neither source can price counts as zero.

## History

Coinbase connections don't read past transactions, so there is nothing to backfill. The balance chart starts on the day you connect, and each sync saves that day's balance. Before that day, the overview counts the account at its first balance, so connecting it doesn't show as growth.

## Common errors

| Message | What it means |
| --- | --- |
| Coinbase rejected the API key. | The key name or private key is wrong, or the key can't view. Check both, or create a new key and connect again. |
| Couldn't read the Coinbase private key. | What you pasted as the private key can't be read as one. Copy it again from the Coinbase Developer Platform. |
| Coinbase is limiting requests. | Coinbase is turning requests away for now. Try again in a few minutes. |
| Coinbase returned an error. | Coinbase had a problem on its side. Try again later. |
| You've already connected this. | This key is already connected. Sync or remove the existing connection instead. |

If a daily sync fails, the error shows on the connection's row and it tries again the next morning. To use a new key, remove the connection and connect again.

For connecting in general, see [Connect accounts](/docs/guides/connect-accounts).
